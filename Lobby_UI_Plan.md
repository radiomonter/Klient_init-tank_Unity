# План работ по доработке интерфейса Lobby (Unity)

Цель: достижение полной визуальной и функциональной идентичности с оригинальным Flash-клиентом.

## Список задач:

1. **Корректировка ярлыков (Заголовков)**
   - Поднять ярлыки "ЧАТ" и "НОВОСТИ" выше (увеличить вертикальный отступ).
   - Прижать ярлыки "СПИСОК БИТВ" и "ИНФОРМАЦИЯ ОБ БИТВЕ" вплотную к соответствующим окнам.

2. **Обновление чата (Визуал + Интерактив)**
   - Изменить спрайты и оформление поля ввода (InputField).
   - Обновить дизайн кнопки "СКАЗАТЬ" (оригинальный стиль).
   - Реализовать отправку сообщения по нажатию клавиши **Enter**.

3. **Исправление иконок рангов**
   - Устранить "квадраты" вместо иконок.
   - Настроить автоматическую привязку спрайтов из каталога: `Assets\Textures\UI\images\ranks`.

4. **Прогресс-бар опыта**
   - Реализовать полосу опыта как в оригинале (с учетом текущего и следующего значения опыта).

5. **Верхнее меню (Header)**
   - Собрать верхнюю панель: кнопки, иконки кристаллов, ранг и имя пользователя в аутентичном стиле.
